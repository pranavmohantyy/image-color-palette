# Image Color Palette Extractor\n\nThis project extracts dominant color palettes from images using k-means clustering.\n\n## Installation\n1. Clone the repository: `git clone <repository-url>`\n2. Install required packages: `pip install pillow numpy`\n\n## Usage\nRun the extractor with your image: `python extractor.py path/to/image.jpg --num_colors 5`\n\n## Example\nBefore and after extracting colors from an image:\n\n![Before](before_image.jpg)\n![After](after_image.jpg)\n\nThe output will be a list of dominant colors in RGB format.
